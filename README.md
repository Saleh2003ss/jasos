# بازی جاسوس — نسخه وب و PWA

یک بازی گروهی فارسی و راست‌چین با طراحی شیشه‌ای پاستیلی، کارت‌های نقش مخفی، تایمر، رأی‌گیری، فرصت حدس کلمه برای جاسوس، امتیازدهی و تاریخچه محلی.

## امکانات این نسخه

- اجرای بازی از ۳ تا ۲۰ بازیکن و انتخاب ۱ تا تعداد بازیکنان منهای ۱ جاسوس
- ۱۰ دسته‌بندی پیش‌فرض شامل ۱۵ کلمه در هر دسته (مجموع ۱۵۰ کلمه)
- فیلتر «همه دسته‌ها»، انتخاب چند دسته و ویرایش بانک کلمات
- پخش نوبتی کارت‌ها روی یک دستگاه، بدون نمایش نقش پیش از لمس دکمه
- تایمر قابل توقف و ادامه، رأی‌گیری گروهی یا مخفی، رأی‌گیری مجدد هنگام تساوی
- حذف بازیکن اشتباه از همان دور، حدس کلمه پس از شناسایی جاسوس و ادامه دور با بازیکنان باقی‌مانده
- امتیازدهی خودکار، دورهای متوالی و رتبه‌بندی پایانی
- ذخیره تنظیمات، نام‌ها، بازی جاری و تاریخچه در LocalStorage
- قابلیت نصب PWA و اجرای بازی اصلی پس از بارگذاری اولیه در حالت آفلاین
- طراحی واکنش‌گرا برای موبایل، تبلت و دسکتاپ، پشتیبانی از حالت تیره و کاهش حرکت

## اجرای سریع روی رایانه

این پروژه به Node.js یا نصب کتابخانه نیاز ندارد.

### روش اول: اجرای مستقیم

می‌توانی `index.html` را در مرورگر باز کنی. بازی در مرورگرهای جدید اجرا می‌شود، اما قابلیت PWA و Service Worker فقط در HTTPS یا محیط `localhost` فعال می‌شود.

### روش دوم: اجرای پیشنهادی با سرور محلی

اگر Python روی رایانه نصب است، در همین پوشه دستور زیر را اجرا کن:

```bash
python -m http.server 8000
```

سپس این آدرس را در مرورگر باز کن:

```text
http://localhost:8000
```

برای توقف سرور، در پنجره ترمینال `Ctrl + C` را بزن.

## انتشار و نصب روی گوشی

برای نصب PWA، پوشه پروژه را روی یک هاست HTTPS منتشر کن. برای مثال می‌توانی تمام فایل‌ها را در یک مخزن GitHub قرار بدهی و GitHub Pages را از بخش Settings → Pages فعال کنی؛ یا پوشه را در Netlify / Cloudflare Pages منتشر کنی.

پس از باز کردن لینک HTTPS:

- در مرورگرهای سازگار اندروید، از گزینه نصب برنامه یا «Add to Home Screen» استفاده کن.
- در آیفون، Share → Add to Home Screen را انتخاب کن.
- پس از بارگذاری اولیه فایل‌ها، بازی اصلی بدون اینترنت هم اجرا می‌شود. نصب و کش آفلاین باید در مرورگر سازگار و روی HTTPS انجام شود.

## داده‌ها و حریم خصوصی

این نسخه بک‌اند یا حساب کاربری ندارد؛ تنظیمات و تاریخچه فقط در مرورگر همان دستگاه ذخیره می‌شود. پاک کردن داده‌های مرورگر ممکن است اطلاعات را حذف کند. برای بازی چندنفره، نقش‌ها روی یک دستگاه مشترک بین افراد پخش می‌شوند؛ این روش جلوی نگاه‌کردن عمدی به صفحه یا بررسی فنی حافظه مرورگر را نمی‌تواند بگیرد. پس از دیدن کارت، بازیکن باید آن را مخفی کند و گوشی را تحویل نفر بعدی بدهد.

## قواعد بازی و امتیازدهی پیش‌فرض

- در هر دور، نقش‌ها و کلمه تازه انتخاب می‌شوند.
- وقتی بازیکن عادی اشتباه انتخاب شود، از رأی‌گیری همان دور کنار می‌رود و بحث ادامه پیدا می‌کند.
- وقتی جاسوس انتخاب شود، در صورت فعال بودن این گزینه فرصت حدس کلمه دارد.
- اگر جاسوس کلمه را درست حدس بزند، تیم جاسوس‌ها برنده دور می‌شود؛ در غیر این صورت، اگر همه جاسوس‌ها شناسایی شوند، بازیکنان عادی برنده می‌شوند.
- پیروزی بازیکنان عادی: هر بازیکن عادی ۳ امتیاز می‌گیرد.
- پیروزی جاسوس‌ها: هر جاسوس آن دور ۳ امتیاز می‌گیرد؛ حدس صحیح جاسوس ۲ امتیاز اضافه دارد.
- در رأی‌گیری مخفی، بازیکنانی که به جاسوس کشف‌شده رأی داده‌اند ۱ امتیاز اضافه می‌گیرند.

می‌توانی فایل `app.js` را برای تغییر دسته‌بندی‌ها، قواعد و امتیازها ویرایش کنی.
